## 关键教训

1. **先判定数据层级，再动手画。** 统计图缺的是数值矩阵；地图缺的是边界/栅格；
   概念图缺的是设计稿。三者不能混为一谈。
2. **公开底图能救地图，但救不了主题值。** 用 DataV/GADM/DEM/WorldCover 可以
   把研究区、地形、土地利用做到“几何真实”；PPFR、连通性、县域碳排放仍然无解。
3. **统计图的“复现”是版式复现。** SHAP 排序、R²、显著性来自数据，不是画出来的。
4. **不需要 ArcGIS。** `geopandas + rasterio + pyproj` 能完成本案例全部地图；
   ArcGIS 只在必须交付 `.aprx` 工程时才需要。
5. **诚实标注比“看起来像”重要。** 每张图都要说明真实层与模拟层。
